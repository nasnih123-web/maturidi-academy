# ADR-0034 — ساختار قواعد سه مذهب دیگر: اسکلت خالی + منابع نام‌برده (M-02)

وضعیت: پذیرفته‌شده (رفع اشکال حسابرسی 197efa0، آیتم M-02)
تاریخ: ۲۰۲۶-۱۰-۲۲

## تصمیم

۱) برای مالکی، شافعی و حنبلی، seed ‏(seed_calculator_rules) حالا —
علاوه بر stub ‏v1 فاز ۷ — یک config ارث **v2 ساختاری** می‌سازد:
اسکلت کامل قرارداد ‏rule_data (ADR-0006: ‏shares / ‏awl / ‏radd /
asaba_priority) با مقادیر **خالی/نامشخص** (shares={}‏،
enabled=None) + وضعیت ‏pending_scholar_entry + منابع کلاسیک
نام‌بردهٔ هر مذهب که عالم جداول را از آن‌ها پر می‌کند:
- مالکی: المدونة الكبرى؛ مختصر خليل با الشرح الكبير للدردير؛ الرسالة لابن أبي زيد.
- شافعی: الأم؛ منهاج الطالبين با مغني المحتاج؛ الرحبية في علم الفرائض.
- حنبلی: المغني لابن قدامة؛ الإنصاف للمرداوي؛ كشاف القناع والروض المربع للبهوتي.

نام کتاب‌ها دادهٔ کتاب‌شناختی است، نه جدول فقهی؛ **هیچ سهم/نرخ/
عددی ساخته نشده** و قانون سخت §۱۵.۵ دست‌نخورده است.

۲) گیت موتور بدون تغییر و یکدست است: ‏get_active_rule فقط
‏status=approved می‌پذیرد؛ هر سه config ساختاری ‏draft‌اند و
‏calculate_inheritance برای هر سه مذهب ‏422 rules_not_approved
می‌دهد — با تست اختصاصی (حتی با حضور config ساختاری).

۳) زکات عمداً مشترک (madhab=null) می‌ماند: config زکاتِ فعلی
طرحاً فرامذهبی است؛ تفاوت‌های مذهبی زکات هم اگر روزی اضافه شوند
فقط از همین مسیرِ config تأییدشدهٔ عالم می‌آیند، نه از این seed.

۴) CRM: نوار «وضعیت مذاهب — ارث» بالای تب قواعد ارث، به‌ازای هر
مذهب تازه‌ترین config را نشان می‌دهد: تأییدشده، یا برچسب هشدار
«در انتظار تأیید عالم» (fa/ar/en). هیچ مذهبی بدون config تأییدشده
«آماده» نمایش داده نمی‌شود.

## وضعیت صریح مذاهب (برای گزارش نهایی)

- **حنفی:** جداول بازثبت‌شده از منبع (فاز ۴) در v2 هست ولی ‏draft —
  در انتظار **بازبینی و تأیید عالم**.
- **مالکی/شافعی/حنبلی:** فقط اسکلت + منابع — در انتظار **ورود
  جداول توسط عالم و سپس تأیید او**.
- نتیجه: محاسبهٔ عمومی ارث برای **هر چهار مذهب** تا تأیید عالم
  بسته است.
