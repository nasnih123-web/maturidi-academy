# ADR-0023: منبع دادهٔ دسکتاپ — پوستهٔ محلی با کانفیگ زمانِ استقرار (نه static export وب)

- وضعیت: پذیرفته‌شده
- تاریخ: 2026-10-21
- میل‌استون: Master Execution Prompt v2 — Phase 6 (Desktop)

## زمینه

- `frontendDist` در `src-tauri/tauri.conf.json` به `../web/out` اشاره می‌کرد،
  اما وب Next.js فعلی هیچ خروجی ایستایی تولید نمی‌کند و نمی‌تواند
  (یافتهٔ F-06 ممیزی): `middleware.ts` برای مسیریابی locale، route
  handlerهای `app/api/search` و `app/api/voice/ask`، و صفحات SSR که
  `API_URL` را سمت سرور می‌خوانند. هیچ build pathای `apps/web/out` نمی‌سازد.
- سه گزینه بررسی شد:
  1. **پروفایل static export جدا برای وب** — نیازمند حذف/دورزدن قابلیت‌های
     سروری یا fork کردن UI وب برای دسکتاپ؛ هزینه و ریسک بالا و دو بیلد وب
     برای نگهداری.
  2. **WebviewUrl::External با URL ثابت** — نشانی production واقعی هنوز
     وجود ندارد (استقراری انجام نشده است)؛ هاردکد‌کردن URL حدسی ممنوع است
     و تغییر نشانی نیازمند rebuild باینری می‌شود. همچنین `main.rs` فعلی
     پنجره را از کانفیگ می‌سازد (`generate_context!`)، نه به‌صورت برنامه‌ای.
  3. **پوستهٔ ایستای محلی داخل `apps/desktop`** که نشانی وب production را
     از فایل کانفیگ همراهش (`shell/config.js`) می‌خواند و به آن navigate
     می‌کند و برای حالت‌های آفلاین/پیکربندی‌نشده صفحهٔ وضعیت داخلی دارد.
- مسائل هم‌زمان: آیکون‌های Tauri روی دیسک نبودند (F-06b — فقط `.gitkeep`)،
  و دو `tauri.conf.json` واگرا در ریپو هست (F-12).

## تصمیم

گزینهٔ ۳:

- `apps/desktop/shell/` (یعنی `index.html` + `shell.js` + `config.js` +
  `icon.png`) فرانت‌اند واقعی پوسته است و `frontendDist` به `../shell`
  تغییر کرد.
- نشانی وب production در `shell/config.js` با متغیر `MATURIDI_WEB_URL`
  **در زمان packaging/استقرار** تنظیم می‌شود. خالی ⇒ صفحهٔ وضعیت داخلی
  «پیکربندی نشده» نمایش داده می‌شود — پوسته هرگز URLای را حدس نمی‌زند یا
  پیش‌فرض جعلی ندارد. آفلاین ⇒ صفحهٔ وضعیت + دکمهٔ تلاش دوباره. در غیر
  این صورت `location.replace` به وب‌اپ واقعی: دسکتاپ همیشه همان وب
  production را با همان قراردادهای API اجرا می‌کند و هیچ منطق محصولی
  داخل پوسته نیست (ADR-001).
- مسیر dev بدون تغییر می‌ماند: `devUrl: http://localhost:3000`.
- آیکون‌های واقعی از نشان مدرسه (`apps/web/public/logo.jpg`) تولید و در
  `src-tauri/icons/` قرار گرفتند: `icon.png`‏ (512)، `32x32.png`،
  `128x128.png`، `128x128@2x.png`، `icon.ico` و `icon.icns` (با Pillow؛
  روی runner مک CI هم با `tauri icon` قابل بازتولید است) و `bundle.icon`
  به همین مجموعهٔ موجود اشاره می‌کند.
- **F-12 — فایل ریشهٔ `apps/desktop/tauri.conf.json` حذف نشد.** محتوایش با
  نسخهٔ `src-tauri` **معنادار واگراست**: updater در آن `active: true` با
  endpointای `example.com` است (در نسخهٔ اصلی صادقانه غیرفعال است)،
  `devUrl` پورت 1420 (در برابر 3000)، `frontendDist` مقدار `../dist`
  (در برابر مسیر پوسته)، CSP متفاوت، و بدون trayIcon/plugins. Tauri 2 این
  فایل را نمی‌خواند (محل قراردادی فقط `src-tauri/tauri.conf.json` است)،
  اما چون نسخهٔ «کپی برابر» نیست، حذفش به بازبینی مالک واگذار شد:
  **توصیهٔ صریح این ADR: مالک پس از بازبینی، فایل ریشه را حذف کند** و تا
  آن زمان هیچ ابزار/اسکریپتی نباید به آن ارجاع دهد.

## پیامدها

- بیلد دسکتاپ دیگر به خروجی وب وابسته نیست؛ `desktop.yml` روی runner
  متناظر هر OS (windows/macos/ubuntu) پوسته را بسته‌بندی می‌کند و یک گام
  sanity وجود فایل‌های پوسته/آیکون را پیش از build بررسی می‌کند.
- بیلد native در sandbox این فاز قابل اجرا نیست (نبود Rust toolchain) —
  وضعیت صادقانه: **NOT TESTED**؛ مسیر CI مستند و آماده است.
- تغییر نشانی production (مثلاً مهاجرت دامنه) فقط با ویرایش `config.js`
  در بستهٔ انتشار ممکن است — بدون rebuild باینری.
- محدودیت صادقانه: تا وقتی وب production مستقر نشود و نشانی واقعی در
  `config.js` قرار نگیرد، باینری دسکتاپ فقط صفحهٔ وضعیت داخلی را نشان
  می‌دهد. این وضعیت در README دسکتاپ و راهنمای استقرار هم ثبت شده است.

## جایگزین‌های ردشده

- **static export وب:** ناسازگار با middleware/route handler/SSR فعلی
  (F-06)؛ بازطراحی بزرگ و خارج از اسکوپ این فاز.
- **WebviewUrl::External ثابت:** قفل‌شدن URL در باینری + نبود URL واقعی
  امروز؛ پوستهٔ محلی همان نتیجه را با کانفیگ زمان استقرار و صفحهٔ خطای
  آفلاین می‌دهد، بدون هیچ تغییری در `main.rs`.
- **نگه‌داشتن `frontendDist: ../web/out`:** مسیر مرده — `out/` هرگز
  تولید نمی‌شود و `tauri build` روی آن شکست می‌خورد.
