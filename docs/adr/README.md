پس از اتمام فاز ۱۷ و به‌روزرسانی ارجاع‌ها، پیشنهاد می‌شود:

1. `0006-phase8-lms.md` → `0016-phase8-lms.md` (رفع تداخل با `0006-phase7-calculators.md`)
2. `001-ui-ux-replaceability.md` → بایگانی شود و به `0002-ui-ux-replaceable.md` ارجاع داده شود
   (هر دو یک تصمیم‌اند؛ نسخهٔ 0002 کامل‌تر و به‌روزتر است)، یا برعکس با تصمیم مالک.
3. `0001-realtime-event-bus.md` دست‌نخورده بماند (با `001` اشتباه گرفته نشود — در این
   فهرست تفکیک شده‌اند).
