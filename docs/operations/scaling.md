# مسیر رشد به ۱۰۰ هزار کاربر — آکادمی ماتریدی

**فاز ۱۷ — 2026-10-19**

## وضعیت فعلی (نقطهٔ شروع)

- API کاملاً stateless است (FastAPI async) — JWT کوتاه‌مدت + refresh چرخشی در Redis/DB؛ هیچ state در حافظهٔ پردازش.
- صف‌ها (ARQ) روی Redis جدا از وب‌سرور.
- جست‌وجو/چت‌بات روی PostgreSQL (+pgvector در تولید)؛ کش Redis برای نشست‌ها و rate-limit.
- تست بار k6 در `tests/load/` — آستانهٔ فعلی را همان‌جا مستند کنید.

## گام‌های مقیاس‌پذیری (به ترتیب)

### ۱. افقی‌کردن API (۰ → ۱۰هزار کاربر هم‌زمان)
- چند replica از کانتینر `api` پشت یک load balancer (NGINX/Traefik).
- **پیش‌نیاز:** هیچ‌کدام — همین حالا stateless است. WebSocket gateway باید sticky-session یا Redis pub/sub داشته باشد (در حال حاضر در-memory است — برای چند replica به Redis adapter منتقل شود).

### ۲. دیتابیس (۱۰هزار → ۵۰هزار)
- Read replica برای PostgreSQL (کوئری‌های خواندنی سنگین: جست‌وجو، فید اجتماعی، گزارش‌ها).
- ایندکس‌های فاز ۱۷ (`f17a0b1c2d3e_phase17_perf_indexes`) نقطهٔ شروع‌اند؛ slow-query log را ماهانه بازبینی کنید.
- pgvector: با رشد چانک‌های RAG، ایندکس IVFFlat/HNSW را tune کنید.

### ۳. کش و CDN (۵۰هزار → ۱۰۰هزار)
- خروجی‌های سنگین و کم‌تغییر (صفحات CMS، لیست کتابخانه) در CDN لبه (Cloudflare) با purge هوشمند پس از انتشار.
- نتایج RAG پرتکرار در Redis (TTL کوتاه).
- فایل‌های استاتیک (فونت/لوگو/مدیا) حتماً از CDN — نه از API.

### ۴. صف و worker (در همهٔ مراحل)
- Workerهای ARQ را جدا scale کنید (رونویسی صوت، OCR، ایندکس RAG).
- محدودیت نرخ درگاه پرداخت و TTS/STT را با رشد کاربران بازبینی کنید.

## چه چیزی scale نمی‌شود (هشدارها)

- **SQLite** فقط برای dev است — تولید حتماً PostgreSQL.
- **MinIO تک‌گره** تا ~ترابایت جواب می‌دهد؛ بعد از آن به S3/کلاستر MinIO مهاجرت کنید.
- **جست‌وجوی تمام‌متن فارسی/عربی** در مقیاس بالا به موتور جدا (Elastic/Meili) نیاز پیدا می‌کند — قرارداد API جست‌وجو (`/api/v1/search`) طوری طراحی شده که پیاده‌سازی عوض شود بی‌آنکه وب/CRM بفهمد.

## برآورد سرانگشتی

با ۲ replica API (۲ vCPU/۴GB)، یک PostgreSQL (۴ vCPU/۱۶GB) و Redis/CDN، رسیدن به ~۱۰هزار کاربر فعال روزانه بدون تغییر معماری واقع‌بینانه است. ۱۰۰هزار نیازمند گام‌های ۲ و ۳ بالاست.
