## ۷. تحویل فاز ۳ — چه داده/فونتی استفاده شود، چه چیزی مسدود است

### ۷٫۱ قابل‌استفاده فوراً (بدون مسدود حقوقی)

1. **Layout ‏QPC V2 ‏۱۵ خطه** (`qpc-v2-15-lines.db`): ۶۰۴ صفحه، ۹٬۰۴۶ خط، با `first/last_word_id` + `is_centered` — جایگزین/تکمیل `quran-mushaf-lines.json` برای highlight/tag کلمه‌ای. مجوز layout تأییدشده (issue #596).
2. **سربرگ‌های SVG سوره‌ها** (۱۱۳ فایل، CC BY 4.0 با انتساب) — به‌جز فاتحه که ندارد.
3. **Tanzil + فونت‌های KFGQPC فعلی** — بدون تغییر، مرجع متن و فونت حفص می‌مانند.
4. **دادهٔ تجوید QUL به‌عنوان مرجع مقایسه** (نه دادهٔ بیلد): ۱۸ کلاس قانون برای سنجش دقت رنگ تجوید دست‌نویس فعلی.
5. **Layoutهای Indopak** (۶۱۰/۸۴۹/۸۴۷ صفحه) از نظر مجوز روشن‌اند — ولی فقط **پس از انتخاب پروفایل IndoPak** و تأمین اسکریپت+فونت سازگار.

### ۷٫۲ مسدود — با دلیل دقیق

| مسدود | دلیل | راه بازشدن |
|---|---|---|
| اسکریپت glyph ‏QPC V2 + فونت‌های ۶۰۴ صفحه‌ای | مجوز QUL نامشخص (صفحهٔ ۲۴۹ و ۶۱ هیچ بخش مجوزی ندارند؛ FAQ ‏#9 بررسی per-resource می‌خواهد) | تماس کتبی با Tarteel (یا KFGQPC) و گرفتن مجوز bundle؛ یا جایگزینی با QCF V2 از Quran Foundation با مجوز جداگانهٔ کتبی |

### ۷٫۳ تصمیم‌های موردنیاز کاربر پیش از فاز ۳ (فهرست کوتاه)

1. **مجوز QUL:** آیا کاربر/تیم با Tarteel تماس می‌گیرد، یا فاز ۳ فقط با layout + SVG جلو برود و مصحف glyph تا تعیین مجوز معلق بماند؟ (پیشنهاد این فاز: جلو رفتن با layout + SVG + Tanzil، بدون bundle اسکریپت/فونت QUL.)
2. **سربرگ فاتحه:** SVG سورهٔ ۱ در مجموعه نیست — طراحی جداگانه یا استفاده از سربرگ فعلی؟
3. **پروفایل IndoPak:** کدام جفت؟ (الف) `qpc-nastaleeq` + layout قدرة‌الله ۱۵ خطه + فونت ۲۴۲/QuranWBW؛ (ب) Digital Khatt Indopak. تا انتخاب نشود، سوییچ CSS فعلی باید «فونت دستگاه» نامیده شود، نه IndoPak.
4. **رنگ تجوید:** آیا دادهٔ ۱۸ کلاسهٔ QUL (پس از مجوز) جایگزین قوانین دست‌نویس شود، یا قوانین فعلی فقط با آن سنجیده شوند؟
5. **Heatmap/تاریخچهٔ خطا روی صفحهٔ مطالعه:** هنوز حذف‌شده بماند یا با تأیید کاربر برگردد؟ (دستور ۲۰۲۶-۱۱-۰۶ همچنان پابرجاست.)
6. **P1-3/P1-4/P1-5** (از گزارش parity) — تصمیم‌های باز.

### ۷٫۴ کارهایی که فاز ۳ نباید بکند

- متن glyph-based ‏QPC V2 را با Unicode عادی جایگزین نکند (قید مأموریت).
- هر ۶۰۴ فونت V2 را یکجا bundle نکند (۲۰۸MB ‏TTF) — فقط lazy-load هر صفحه پس از مجوز.
- همهٔ پروفایل‌ها (V1/V4/IndoPak/Nastaleeq/Digital Khatt/13-line) را بدون دلیل در بیلد اصلی فعال نکند.
- شناسه‌های QUL را بدون جدول تبدیل در حفاظ به‌کار نبرد (۴٬۶۳۵ آیه شمار متفاوت).
- فایل «V4» را جدا از «V2» وارد نکند — یکی‌اند.
- هیچ فایل موجودی را بدون بررسی حذف/جایگزین نکند؛ هیچ تکراری‌ای نسازد (`qul-downloads` همان فایل‌ها را دارد).
