# نقشهٔ صفحات — آکادمی ماتریدی (Page Map)

> مالک: ترک وب — فاز ۳. وضعیت: 2026-10-18
> هر سطر یک صفحه/مسیر است با یک خط توضیح. ستون «وضعیت» می‌گوید صفحه الان هست یا در کدام فاز می‌آید.
> قرارداد: همهٔ صفحات فقط مصرف‌کنندهٔ قراردادهای API هستند (ADR-0002) — بازسازی UI هرگز بک‌اند را عوض نمی‌کند.
> فاز ۴ وب (2026-10-18): لایهٔ CMS وب به قرارداد `GET /api/v1/content/public/*` بک‌اند بسته شد —
> صفحهٔ داینامیک، ناوبری دیتابیسی، بنرها/اعلان‌ها، صفحات حقوقی واقعی، رویداد اسلامی و نقل‌قول علما.

## موبایل (`apps/mobile`) و دسکتاپ (`apps/desktop`)

- هر دو: **همان ماژول‌های وب** با ناوبری نیتیو (تب/دراور/استک) — برابری کامل عملکردی با وب در هر فاز (فاز ۱۳).
- وضعیت فعلی: `apps/mobile` خالی؛ `apps/desktop` فقط اسکافولد Tauri (فاز ۲). صفحات واقعی از فاز ۱۳ به بعد.
- قرارداد مشترک: مصرف همان `/api/v1/*`، همان توکن‌های `@maturidi/design-tokens` (نسخهٔ `tokens.ts`)، همان گردش‌کار محتوا.

## نکته‌های IA

- همهٔ مسیرهای وب locale-prefix دارند (`/fa/…`، `/ar/…`، `/en/…`)؛ پیش‌فرض `fa`.
- هیچ صفحه‌ای متن هاردکد ندارد: همهٔ رشته‌ها از `messages/*.json` (next-intl) یا API می‌آیند (§۱۵.۴).
- صفحهٔ جدید = مصرف‌کنندهٔ جدید قرارداد موجود؛ اگر قراردادی لازم بود اول ADR، بعد API، بعد UI.
