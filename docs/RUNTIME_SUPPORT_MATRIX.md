## Upgrade policy notes

- Runtime bumps are deliberate, single-purpose commits: version-sensitive
  tooling (mypy/ruff) counts drift between tool versions, so pins change
  only with a full-suite re-verification (see
  `audit-v2/TYPE_DEBT_BURNDOWN.md`).
- Weekly dependency updates are proposed by Dependabot
  (`.github/dependabot.yml`) — grouped minor/patch, reviewed by a human;
  majors and runtime bumps stay manual.
