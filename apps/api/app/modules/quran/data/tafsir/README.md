# تفسیرهای فارسی باندل‌شده (QUL) — راهنمای نصب داده

این پوشه جای فایل‌های دادهٔ دو تفسیر فارسی کاتالوگ QUL است (همان
منبعی که ترتیل از آن دانلود می‌کند):

- `fa.mokhtasar.json` — تفسیر مختصر به فارسی
- `fa.saadi.json` — تفسیر سعدی به فارسی

## چرا فایل‌ها داخل ریپو نیستند؟

دانلود دیتاست‌های QUL از qul.tarteel.ai حساب کاربری می‌خواهد
(بدون لاگین HTTP 401 برمی‌گردد؛ در گام ۱ و ۵ این PR راستی‌آزمایی
شده). پس داده را مالک پروژه با حساب خودش می‌گیرد — دقیقاً مثل
دارایی‌های تشخیص گام ۳ که از درایو تحویل شدند.

## نصب (دو فایل، یک بار)

1. از QUL دیتاست sqlite هر دو تفسیر فارسی را دانلود کنید.
2. از پوشهٔ `apps/api` اجرا کنید:

   ```
   python3 scripts/import_qul_tafsir.py mokhtasar.sqlite fa.mokhtasar
   python3 scripts/import_qul_tafsir.py saadi.sqlite fa.saadi
   ```

   importer شکل جدول را تشخیص می‌دهد و پوشش کامل ۶۲۳۶ آیه را
   سخت‌گیرانه راستی‌آزمایی می‌کند؛ فایل ناقص نصب نمی‌شود.
3. تمام است: provider باندل‌شده (`bundled`) فایل‌ها را تنبل
   می‌خواند، پاسخ `GET /api/v1/quran/providers` آن‌ها را در
   `bundled_tafsirs` اعلام می‌کند و ریدر وب فقط آن‌وقت این دو
   تفسیر را در انتخاب‌گر نشان می‌دهد. تا پیش از نصب، این
   editionها در هیچ فهرستی نیستند و درخواست مستقیمشان خطای
   صادقانهٔ «داده نصب نیست» می‌گیرد، نه محتوای ساختگی.
