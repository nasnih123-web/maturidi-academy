# تفسیرهای فارسی باندل‌شده — راهنمای نصب داده

این پوشه جای فایل‌های دادهٔ دو تفسیر فارسی است (همان‌هایی که
ترتیل در کاتالوگ QUL دارد):

- `fa.mokhtasar.json` — تفسیر مختصر به فارسی — ✅ **نصب شد**
  (گام ۷ توسعه، ۲۰۲۶-۱۱-۱۲: دیتاست `persian-mokhtasar` تحویلی
  مالک از درایو؛ پوشش کامل ۶۲۳۶ آیه؛ دو ردیف گروهی QUL
  (۵۶:۵۱–۵۲ و ۱۰۷:۴–۵) طبق اعلان ayah_keys خود منبع گسترش یافتند.)
- `fa.saadi.json` — تفسیر سعدی به فارسی — ✅ **نصب شد**
  (تکمیل گام ۷، ۲۰۲۶-۱۱-۱۲). سعدیِ فارسی در کاتالوگ دانلودی QUL
  نیست (فایل‌های تحویلی مالک راستی‌آزمایی شدند: `sq-saadi`
  آلبانیایی، `tafsir-as-saadi` عربیِ اصل، و `persian_ih.pdf`
  ترجمهٔ رواد بود)؛ تنها منبع رسمی‌اش **QuranEnc** است (کلید
  `persian_saadi`). نصب با مبدل `scripts/import_quranenc_tafsir.py`
  انجام شد که داده را از API رسمی QuranEnc می‌گیرد و از همان
  مسیر سخت‌گیرانهٔ importer عبور می‌دهد. پوشش: ۶۲۳۳ آیه — نسخهٔ
  رسمی سه ورودیِ خالیِ مشروع دارد (۲:۲۱۲، ۲۸:۱۶، ۵۶:۴۳)؛ برای
  آن‌ها متن ساخته نشده و provider خطای صادقانه می‌دهد.

## چرا فایل‌ها با دانلود ساده داخل ریپو نیامدند؟

دانلود دیتاست‌های QUL از qul.tarteel.ai حساب کاربری می‌خواهد
(بدون لاگین HTTP 401 برمی‌گردد؛ در گام ۱ و ۵ این PR راستی‌آزمایی
شده). مختصر را مالک پروژه با حساب خودش گرفت و تحویل داد؛ سعدیِ
فارسی اصلاً در آن کاتالوگ نیست و از API عمومی QuranEnc آمد.

## نصب / بازنصب

- مختصر (از sqlite ٔQUL تحویلی مالک)، از پوشهٔ `apps/api`:

  ```
  python3 scripts/import_qul_tafsir.py mokhtasar.sqlite fa.mokhtasar
  ```

- سعدی (از API رسمی QuranEnc)، از پوشهٔ `apps/api`:

  ```
  python3 scripts/import_quranenc_tafsir.py
  ```

  importer شکل جدول را تشخیص می‌دهد و پوشش را سخت‌گیرانه
  راستی‌آزمایی می‌کند (برای fa.saadi دقیقاً با همان سه استثنای
  مستند)؛ فایل ناقص نصب نمی‌شود.
- تمام است: provider باندل‌شده (`bundled`) فایل‌ها را تنبل
  می‌خواند، پاسخ `GET /api/v1/quran/providers` آن‌ها را در
  `bundled_tafsirs` اعلام می‌کند و ریدر وب فقط آن‌وقت این دو
  تفسیر را در انتخاب‌گر نشان می‌دهد. تا پیش از نصب، این
  editionها در هیچ فهرستی نیستند و درخواست مستقیمشان خطای
  صادقانهٔ «داده نصب نیست» می‌گیرد، نه محتوای ساختگی.
