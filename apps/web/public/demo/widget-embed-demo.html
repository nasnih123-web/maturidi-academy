ویجت‌های قابل‌جاسازی آکادمی ماتریدی

این صفحه خارج از پروژه است و ویجت‌ها را دقیقاً مثل یک سایت خارجی، از روی endpointهای عمومی /api/v1/widgets/* بارگذاری می‌کند.

نکتهٔ فنی: هر ویجت فقط یک <div class="ma-widget" …> به‌علاوهٔ اسکریپت بارگذار زیر است — همان قالبی که مولد کد embed در CRM تولید می‌کند. مبنای API را می‌توان با data-api-base یا پارامتر ?api_base= عوض کرد.
