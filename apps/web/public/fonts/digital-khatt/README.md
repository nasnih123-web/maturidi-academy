# Digital Khatt Fonts — فونت‌های دیجیتال‌خط

## فارسی

این پوشه شامل فونت متغیر **Digital Khatt V2** (مدینهٔ جدید) است — فونت پارامتریکِ امین عنان (Amine Anane) و Tarteel که خط مصحف مدینه را به‌صورت متن واقعی یونیکد رندر می‌کند و با محور تغییر `SCLX` و قابلیت‌های توجیه (cv01–cv18 ،`jalt` ،`basm`) خط را با کشیدنِ *داخل* کلمات پر می‌کند، نه با فاصلهٔ بین کلمات.

**مجوز — SIL OFL 1.1 (باز و روشن):** مجوز داخل خود فایل فونت حک شده است (nameID 13: «This Font Software is licensed under the SIL Open Font License, Version 1.1»). متن کامل مجوز در `OFL.txt` همین پوشه است. تبدیل قالب (OTF ← WOFF2) و میزبانی شخصی تحت OFL مجاز است.

**منبع و راستی‌آزمایی:**
- منبع اصلی: QUL (پلتفرم دادهٔ باز Tarteel)، منبع فونت ۲۴۷ — https://qul.tarteel.ai/resources/font/247
- دانلود مستقیم از QUL نیازمند حساب کاربری است (در ۲۰۲۶-۱۱-۱۲ بدون ورود، HTTP 401 برگشت) و این پروژه حساب QUL ندارد؛ پس فایل از نسخهٔ توزیع‌شدهٔ همان فونت در بستهٔ اپ Tarteel (APK رسمی که مالک پروژه ارائه کرده) گرفته شد — همان فایلی که خود Tarteel با آن رندر می‌کند.
- **SHA-256 فایل OTF:** `0a70b87756eb1a96f91858ab8041521291db94deaa1f97f021bbb4393ba0aa8d` — حجم ۵٬۷۴۷٬۴۸۰ بایت، دقیقاً برابر حجم اعلام‌شدهٔ فایل QUL.
- **WOFF2:** تبدیل بدون‌اتلاف با fontTools از همان OTF (۳٬۷۳۴ گلیف و محور SCLX و همهٔ قابلیت‌های GSUB پیش و پس از تبدیل یکسان‌اند)؛ مجوز OFL این تبدیل را مجاز می‌داند.

**دادهٔ همراه:** متن کلمه‌به‌کلمهٔ «Digital Khatt Quran script» و چیدمان «Digital Khatt (KFGQPC V2 1421H print)» (منبع ۲۱ QUL) در `apps/web/public/quran-mushaf-dk*.json` — تولیدشده با `apps/web/scripts/generate-quran-mushaf-dk.py`؛ سابقه و وضعیت داده در `THIRD_PARTY_NOTICES.md` ثبت شده است.

## English

This folder contains the **Digital Khatt V2** variable font (New Madina) — Amine Anane's and Tarteel's parametric font, which renders the Madina mushaf hand as real Unicode text and justifies lines by elongating *inside* words (the `SCLX` variation axis and the `cv01–cv18` / `jalt` / `basm` justification features), not by widening inter-word spaces.

**Licence — SIL OFL 1.1 (open):** the licence is embedded in the font file itself (nameID 13: "This Font Software is licensed under the SIL Open Font License, Version 1.1"). The full licence text is `OFL.txt` in this folder. Format conversion (OTF → WOFF2) and self-hosting are permitted under the OFL.

**Provenance & verification:**
- Upstream source: QUL (Tarteel's open-data platform), font resource 247 — https://qul.tarteel.ai/resources/font/247
- QUL's direct download requires an account (verified 2026-11-12: HTTP 401 while logged out) and this project has no QUL account; the file was therefore taken from the same font as distributed in the Tarteel app bundle (the official APK provided by the project owner) — the very file Tarteel itself renders with.
- **OTF SHA-256:** `0a70b87756eb1a96f91858ab8041521291db94deaa1f97f021bbb4393ba0aa8d` — 5,747,480 bytes, exactly the size of QUL's official file.
- **WOFF2:** lossless fontTools conversion of the same OTF (3,734 glyphs, the SCLX axis and all GSUB features identical before/after); the OFL permits this conversion.

**Companion data:** the "Digital Khatt Quran script" word text and the "Digital Khatt (KFGQPC V2 1421H print)" layout (QUL resource 21) live in `apps/web/public/quran-mushaf-dk*.json`, generated by `apps/web/scripts/generate-quran-mushaf-dk.py`; provenance and data status are recorded in `THIRD_PARTY_NOTICES.md`.
